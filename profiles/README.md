# Библиотека профилей FRAIM Beta 💚

**Разработчик FRAIM: SHUK**

Здесь можно размещать пользовательские профили игр для обмена с другими игроками. Обмен работает через файлы `.fraim.json`: никакого аккаунта FRAIM или обязательного облачного сервиса не требуется.

**Состояние:** библиотека открыта для будущих профилей, импорт/экспорт появится после выпуска FRAIM Beta v42. Пока встроенного каталога с кнопкой «Скачать профиль» в приложении нет.

## Как поделиться своим пресетом
1. В FRAIM Beta v42 выбери игровой профиль, создай области и нужные пресеты.
2. Выбери **«Сохранить активный профиль в файл»**, получи `.fraim.json`.
3. Проверь содержимое файла, чтобы в нём не было личных заметок в названиях.
4. Открой Pull Request в репозиторий `Lilpupok/FRAIM-releases` и добавь профиль в каталог `profiles/` с именем игры в имени файла. В описании укажи игру, платформу, разрешение и версию FRAIM.

Если не умеешь пользоваться Pull Request, открой [GitHub Issue](https://github.com/Lilpupok/FRAIM-releases/issues) и приложи файл/ссылку без персональной информации.

## Безопасность
- **Не публикуй:** пароль PSN, токены, ключи Remote Play, домашний IP или фотографии личных сообщений.
- Экспортёр FRAIM сохраняет только разрешённые настройки OCR и пресетов. Тем не менее перед отправкой разумно просмотреть файл.
- Импорт из неизвестных источников осуществляется пользователем на свой риск. FRAIM проверяет формат и создаёт отдельный профиль, не изменяя существующий.
- Для новых версий JSON может появиться новый номер схемы.
