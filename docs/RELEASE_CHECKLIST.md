## Нейминг и совместимость
Пользовательские экраны, описания и релизные заметки: только **FRAIM Beta** до решения о Stable 1.0.

Внутренние значения `applicationId=org.fraim.alpha` и старое имя `fraim-alpha.apk` (пока требуется для старых апдейтеров) **не переименовывать без миграционного плана**. Для нового релиза можно публиковать `fraim-beta.apk` одновременно с историческим именем до обновления клиентов.

**Не называй Beta «Stable 1.0» до завершения ручного QA, проверки приватности, лицензий и воспроизводимости сборки.**
