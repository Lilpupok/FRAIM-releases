# Чек-лист перед первым публичным выпуском FRAIM

**Статус:** подготовка. Не считай готовность GitHub-страницы подтверждением готовности к распространению APK.

## Юридические и пользовательские требования

- [ ] Проверены условия AGPLv3 и совместимость остальных зависимостей (включая Google ML Kit).
- [ ] Вместе с бинарником подготовлен **соответствующий исходный код** всех обязательных модификаций, лицензии, copyright-уведомления, инструкции сборки и точные исходные версии.
- [ ] Завершена оценка правовых рисков стороннего PlayStation Remote Play и использования игровых брендов.
- [ ] Подготовлена политика конфиденциальности, ясно описаны OCR-телеметрия, передача распознанного текста переводчику и работа с регистрационными данными PSN.
- [ ] Никаких API-токенов, паролей, ключей подписи и других секретов в APK, репозитории или логах.

## Подпись и безопасная публикация

- [ ] Создан **постоянный закрытый JKS-ключ**, сделана безопасная резервная копия вне GitHub.
- [ ] Секреты добавлены в приватный репозиторий сборки: `FRAIM_KEYSTORE_B64`, `FRAIM_STORE_PASSWORD`, `FRAIM_KEY_ALIAS`, `FRAIM_KEY_PASSWORD`.
- [ ] На одной и той же подписи протестированы **две последовательные версии** APK: vN и vN+1. Установка поверх предыдущей сохраняет регистрацию и настройки.
- [ ] Публичный GitHub Release содержит `fraim-alpha.apk`, сведения о версиях, обязательные исходники и SHA-256; названия и тег соответствуют контракту Updater.
- [ ] Тег релиза для сборки с `versionCode=15` имеет формат `fraim-alpha-v15`; следующий должен иметь большее число, без повторного использования старого versionCode.
- [ ] Для каждого APK опубликованы дата, список изменений и известные ограничения.
- [ ] Проверена работа скачивания и **подтверждаемой Android установки** через Updater.

## Ручное тестирование

- [ ] Проверена установка на Xiaomi TV Box S 3rd Gen (32-bit ABI).
- [ ] Запускается PS5 Remote Play и сохраняется управление геймпадом.
- [ ] Работает Vision ON/OFF и обе области OCR.
- [ ] Translate требует согласие на передачу текста и ясно показывает ошибки бесплатного сервиса.
- [ ] Длительный игровой тест без утечек памяти, неустойчивых переводов и разрывов соединения.

## Что пока блокирует первый публичный APK

Пока **не выполнены требования по постоянной подписи и публикации соответствующих исходников**, не публиковать тестовые APK для массового скачивания.

Этот список — рабочий документ разработчиков, а не юридическое заключение.
