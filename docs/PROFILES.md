# Обмен профилями FRAIM Beta (.fraim.json)
**Разработчик:** SHUK · **Статус:** функция подготовлена для Beta v42, не входит в v41

## Что делает общий профиль
Профиль позволяет обменяться настройками перевода конкретной игры: координатами обеих областей OCR, размером и стилем отображения текста, списком пресетов («Игровой процесс», «Телефон», «Инвентарь») и выбранным пресетом.

Файл **не содержит** PSN-логин, пароль, токены, регистрационные ключи Remote Play, адрес консоли, кадры трансляции, распознанные или переведённые диалоги. Это не сохранение самой игры и не перенос регистрации PS5.

## Как отправить профиль (начиная с Beta v42)
1. Открой FRAIM → **Профили игр**, выбери нужную игру.
2. Выбери **«Поделиться активным профилем»** и укажи приложение для отправки.
3. Если на Android TV нет подходящего приложения, используй **«Сохранить активный профиль в файл»**, выбери папку и отправь сохранённый файл любым удобным способом.

Результат имеет имя наподобие \`FRAIM_South_Park.fraim.json\`.

## Как импортировать
1. Скачай файл профиля на Android TV (из доверенного источника).
2. Открой **Профили игр → Импортировать файл профиля**.
3. Найди файл в системном выборе документов, прочитай название игры и количество пресетов.
4. Подтверди импорт: FRAIM создаст **новый пользовательский профиль**. Если название уже используется, к нему добавится номер. Старый профиль не перезаписывается.
5. Переподключи Remote Play для применения геометрии и параметров.

Некоторые Android TV могут не иметь встроенного средства выбора документов или отправки файлов. В таком случае потребуется совместимый файловый менеджер.

## Формат
Публичный формат JSON (\`schema: 1\`) с ключами \`format: "fraim-game-profile"\`, \`game\`, \`settings\` и \`scenes\`. FRAIM проверяет тип файла, диапазоны координат, ограничения пресетов и максимальный размер 128 КиБ. Незнакомые поля игнорируются при импорте и не переносятся в настройки приложения.
