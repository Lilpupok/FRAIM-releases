# Установка FRAIM Beta на Android TV
**Разработчик:** SHUK · **Статус:** Beta · обновлено 16 ноября 2026 г.

## Первичная установка
1. Открой [FRAIM Releases](https://github.com/Lilpupok/FRAIM-releases/releases/latest) и выбери актуальный релиз.
2. Скачай APK. Начиная с v42 основной файл называется `fraim-beta.apk`, а историческое имя `fraim-alpha.apk` оставлено только для старых апдейтеров: **сама программа является Beta**.
3. Перенеси APK на устройство с помощью браузера, сетевого диска или файлового менеджера.
4. В Android TV разреши установку из этого источника и подтверди системный диалог.
5. Открой FRAIM, подключи собственную PlayStation 5 через Remote Play и настрой области распознавания.
6. Выбери перевод: офлайн Bergamot WebAssembly или (по своему согласию) онлайн MyMemory.

## Обновление без потери данных
Открой **Система → Проверить обновления**. FRAIM загрузит файл GitHub Release, проверит размер, SHA-256, название пакета и номер версии, затем передаст файл стандартному установщику Android. Установка требует подтверждения пользователя.

**Не удаляй существующую версию** перед обновлением: удаление может очистить локальные профили, конфигурацию и регистрацию PS5. Идентификатор пакета `org.fraim.alpha` оставлен неизменным для Android-совместимости, это не обозначение стадии Alpha.

Если Android сообщает о конфликте подписей, не удаляй приложение сразу. Сообщи версию и текст ошибки в [Issues](https://github.com/Lilpupok/FRAIM-releases/issues).

## Игровые профили и пресеты
В профиле игры можно настроить две области OCR и отдельные пресеты для «Игры», «Телефона», «Инвентаря». Для полного экрана используй «Сканировать экран»; после прокрутки повтори сканирование.

Начиная с **FRAIM Beta v42**, в разделе «Профили игр» можно сохранить активный профиль в `.fraim.json`, поделиться им через приложения Android или импортировать чужой профиль. Для импортированного файла создаётся отдельная копия; регистрационные данные PS5 не переносятся. [Инструкция по обмену профилями](PROFILES.md).

## Translation Memory (Beta v44)
После обновления в разделе **Перевод → Translation Memory** можно импортировать CSV с английскими и русскими репликами. Поддерживаются заголовки `english,russian` и `source,translation`; пустые русские ячейки игнорируются. Импорт выполняется локально и не изменяет подключение PS5. В следующей трансляции готовые переводы используются до обращения к Bergamot или MyMemory. Если совпадение не найдено, обычный перевод продолжает работать.

Для передачи CSV с iPhone на Android TV подойдёт доступный файловый менеджер или облачное приложение, а системный выбор файла может требовать файловый менеджер на приставке. Подробности: [Translation Memory](TRANSLATION_MEMORY.md).

## Контроллер DualSense (Beta v43)
Открой **Система → Геймпад** для просмотра подключения и заряда. Во время игры открой быстрое меню FRAIM: статус обновляется после подключения/отключения геймпада и каждые 30 секунд, пока меню открыто. На некоторых Android TV процент заряда не передаётся системой: в таком случае будет написано «Заряд неизвестен». Это не ошибка Remote Play и не ограничение заряда контроллера. Управление DualSense новой функцией не изменяется.

## Диагностика
- Убедись, что PS5 поддерживает и разрешает Remote Play, а устройство подключено к сети
- Проверь включение Vision и Translate в FRAIM
- При проблемах с производительностью верни стандартный интервал OCR
- Онлайн MyMemory может ограничивать переводы; офлайн Bergamot не имеет квоты онлайн-провайдера
- Для обратной связи укажи версию, модель Android TV и сценарий воспроизведения без секретов подключения
