# Установка FRAIM на Android TV

> **Раннее тестирование:** публичный APK пока не опубликован. Эта инструкция предназначена для будущих релизов.

1. Открой страницу [FRAIM Releases](https://github.com/Lilpupok/FRAIM-releases/releases).
2. Выбери выпуск и прочитай список изменений и предупреждения.
3. Скачай **`fraim-alpha.apk`**. Проверяй, что файл опубликован в официальном репозитории FRAIM Releases.
4. Перенеси APK на Android TV и открой его через файловый менеджер. Android может попросить разрешить установку из этого источника.
5. Подтверди установку. Для работы Remote Play подключи к FRAIM свою PlayStation с помощью обычной регистрации.
6. В игре включи Vision, настроив зелёную рамку под субтитры. Translate по умолчанию выключен и включается только с согласия на онлайн-перевод.

## Обновления

Когда релизный канал и постоянная цифровая подпись заработают, открой **FRAIM Updater → Проверить обновления**, а затем подтверди скачивание и системную установку. Автоматическая загрузка не означает тихую установку: Android попросит подтверждение.

Если Android сообщает **«конфликт пакетов»**, наиболее вероятная причина — подписи APK различаются. Не удаляй приложение без понимания последствий: при удалении могут пропасть настройки и регистрация PlayStation. Для старых экспериментальных APK однократная переустановка может оказаться необходимой.

## Что делать при ошибке

- Убедись, что скачан APK для Android TV, содержащий `armeabi-v7a` и `arm64-v8a`.
- Для онлайн-перевода проверь интернет и дневной лимит тестового провайдера.
- Сведения об ошибках отправляй в [Issues](https://github.com/Lilpupok/FRAIM-releases/issues), но **не публикуй** PSN-токены, пароль, IP-адрес домашней сети и другие личные данные.

Приложение независимое и не одобрено Sony Interactive Entertainment.
