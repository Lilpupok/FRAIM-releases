# Игровые профили с локализацией · FRAIM Beta v45

**Разработчик:** SHUK · **Версия:** FRAIM 1.2 Beta 2 (v45).

Игровой профиль теперь может иметь **свою локальную базу переводов**.
FRAIM автоматически использует эту базу, когда выбран соответствующий
профиль игры. Если совпадений с распознанным OCR-текстом нет, продолжает
работать стандартный Bergamot или согласованный онлайн-перевод MyMemory.

## Установка игрового пакета

1. Обнови FRAIM до Beta v45 через **Система → Проверить обновления**.
2. Перенеси игровой файл `.fraimpack` на Android TV.
3. Открой **Профили игр → Локализации в профилях**.
4. Нажми **Установить игровой пакет (.fraimpack)**.
5. Выбери файл. FRAIM распакует его локально, проверит содержимое, привяжет
   переводы к указанной игре и выберет её профиль.
6. Запусти Remote Play: нужная база подключится автоматически.
   При выборе другого профиля она перестанет применяться.

Если Android TV не показывает файл `.fraimpack`, можно переименовать
его в `.zip`: формат внутри обычный ZIP. Некоторые файловые менеджеры
на телевизионных приставках требуют отдельной установки.

## Формат для авторов локализаций

Файл ZIP с расширением `.fraimpack` содержит:
- `manifest.json` с `format=fraim-game-bundle`, `schema=1` и названием `game`.
- `translations.csv`: пары `english,russian` или `source,translation`.
- `profile.fraim.json` (необязательно): настройки областей OCR и сцен,
  экспортированные из FRAIM и соответствующие той же игре.

Пример `manifest.json`:

```json
{
  "format": "fraim-game-bundle",
  "schema": 1,
  "game": "Название игры"
}
```

Пример **вымышленных** строк CSV:

```csv
english,russian
"Open inventory","Открыть инвентарь"
"Select a character","Выбрать персонажа"
```

Данные хранятся отдельно для разных игровых профилей. Обычный файл
`.fraim.json` по-прежнему содержит **только настройки**, а не игровые
тексты. Для установки переводов вместе с настройками используй
`.fraimpack`.

## South Park и авторские права

Для пользовательского тестирования подготовлен отдельный черновой пакет
South Park из 7 500 пар. **Он не входит в публичный APK** и не размещён
на GitHub Releases, потому что в нём есть тексты игры Ubisoft, права на
распространение которых не подтверждены. Автор игры сохраняет права
на оригинальные материалы; разрешение другого моддера не заменяет
разрешение правообладателя.

Благодарим **Sanka (stamp45240)** за предоставленные английские исходные
строки для разработки механизма. Его тайский перевод не включается в FRAIM.

## Совместимость и ограничения

- Устанавливай обновление поверх текущего, **не удаляя FRAIM**.
- Устаревшая общая база v44 остаётся доступна в профиле South Park,
  пока не заменена индивидуальным игровым пакетом.
- В v45 нет публичного каталога автоматических скачиваний: базы подключаются
  **автоматически после однократной установки пакета**, но сам пакет
  пользователь предоставляет из разрешённого источника.
- На Xiaomi TV Box S (3rd Gen) установка и переключение профилей ещё
  требуют проверки в реальной игре.
