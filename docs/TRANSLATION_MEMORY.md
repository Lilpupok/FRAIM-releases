# FRAIM Translation Memory · Beta v44

**Разработчик:** SHUK · **Режим:** локальный пользовательский перевод игр.

В v44 FRAIM сначала ищет точное совпадение английского текста из OCR
в пользовательском словаре. Если найдёт русский вариант, выводит его
без вызова Bergamot. Если совпадения нет, включается обычный переводчик
Bergamot или MyMemory в соответствии с настройками.

## Без ПК: как загрузить языковой пакет

1. Подготовь на iPhone файл CSV в кодировке UTF-8 с двумя столбцами
   `english,russian` (или `source,translation`).
2. Перенеси CSV на Android TV привычным файловым менеджером или облачным
   приложением, доступным на телевизионной приставке.
3. В FRAIM зайди в **Перевод → Translation Memory → Импортировать языковой CSV**.
4. Выбери файл через стандартный выбор документов Android TV.
5. Проверь сообщение о количестве загруженных русских фраз и запусти
   трансляцию PS5.

Для работы требуется **не только английский оригинал, но и заполненный
русский перевод**. Оригинальный английский CSV без русских строк не
превратится в готовую русскую локализацию автоматически.

## Формат CSV

```csv
english,russian
"Open inventory","Открыть инвентарь"
"Select character","Выбрать персонажа"
```

Пример выше вымышленный и предназначен только для демонстрации формата.

Импортёр также понимает названия столбцов `source` и `translation`:
такой формат использует таблица локализационных данных South Park, полученная
разработчиком при содействии участника сообщества.

- Пустые русские строки пропускаются.
- Неоднозначные одинаковые английские фразы с *разными* русскими переводами
  исключаются, чтобы не показывать случайную реплику.
- Поиск строгий, с нормализацией регистра, пробелов и знаков препинания;
  приблизительные совпадения пока отключены во избежание ошибок.
- Некоторые разбитые по времени диалоги поддерживают поиск по сегментам,
  если английские и русские фрагменты в CSV сопоставлены.
- Ограничения импорта: до 32 МиБ CSV и 120 000 строк.
- В v44 поддерживается одна активная база, а не отдельные базы на каждую игру.

## Приватность и лицензии

База хранится в приватном SQLite-хранилище Android TV. Сам модуль Translation
Memory **не отправляет** импортированный файл или результат поиска в сеть.
Однако обычный онлайн-перевод MyMemory при отсутствии совпадения продолжает
подчиняться отдельному согласию пользователя.

**FRAIM не распространяет полную локализацию Ubisoft в APK.** Загружайте
только тексты, использовать которые у вас есть право. Материалы сторонних
моддеров нельзя переиздавать без соответствующих разрешений.

Благодарность **Sanka (stamp45240)** за добровольно предоставленную таблицу
английских строк и идентификаторов South Park. Его тайский мод и переводы
не включены в FRAIM: [страница локализации на Nexus Mods](https://www.nexusmods.com/southparkthefracturedbutwhole/mods/69).
