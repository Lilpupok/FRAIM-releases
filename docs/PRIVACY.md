# Конфиденциальность FRAIM · предварительная политика Alpha

Дата редакции: 13 ноября 2026 г.

FRAIM — экспериментальный независимый клиент Remote Play с распознаванием и переводом игрового текста на Android TV. Этот документ описывает текущую тестовую версию Alpha 0.4. Перед полноценным публичным запуском требования законодательства и условия сторонних сервисов ещё нужно проверить.

## Какие данные обрабатываются

**Кадры игры:** захватываются внутри приложения для поиска текста. OCR работает на устройстве через библиотеку Google ML Kit. Само изображение не отправляется сервису перевода FRAIM.

**Распознанный текст:** только если пользователь вручную включил Translate и подтвердил предупреждение, фрагменты английского текста отправляются через HTTPS сервису **MyMemory / Translated** для перевода на русский. Отправка производится запросом к `api.mymemory.translated.net`, поэтому сервис и сетевые посредники могут обрабатывать текст запроса, IP-адрес и технические данные подключения. Политика и сроки хранения стороннего сервиса определяются его собственными условиями. Не следует использовать онлайн-перевод для конфиденциальных текстов.

**Регистрация Remote Play:** сведения, необходимые для подключения к PlayStation, обрабатываются компонентом Chiaki-ng на устройстве. FRAIM Translate не должен передавать эти сведения сервису перевода.

**Технические настройки:** состояние Vision/Translate, положение областей и настройки захвата хранятся локально в настройках приложения. В текущей реализации FRAIM не имеет собственного сервера учётных записей.

## Как управлять обработкой

- Онлайн-перевод **по умолчанию выключен**. Для включения необходимо подтвердить отправку распознанного текста MyMemory.
- Выключение `TRANSLATE: ВЫКЛ` прекращает новые переводы. Уже отправленный стороннему сервису запрос невозможно отозвать.
- Для сброса локальных настроек и ранее сохранённого согласия можно очистить данные приложения в настройках Android TV. Это также удалит локальную регистрацию PlayStation, и её потребуется повторить.
- FRAIM не требует создания собственной учётной записи и не запрашивает оплаты за перевод.

## Ограничения

FRAIM использует сторонний OCR SDK и сетевой сервис перевода. У этих поставщиков могут быть собственные правила обработки технических данных и телеметрии. Данный документ не заменяет их политики и не гарантирует отсутствие любых сетевых обращений сторонних библиотек.

Не публикуйте в GitHub Issues пароли, PSN-токены, домашние IP-адреса или личную переписку.
