# Конфиденциальность FRAIM Beta
**Разработчик:** SHUK · **Обновлено:** 16 ноября 2026 г.

Этот документ описывает известную архитектуру публичной Beta v44 с обменом игровыми профилями. Он не является юридическим заключением.

## Какие данные обрабатываются
- **Кадры Remote Play:** FRAIM получает изображение локально внутри собственного сеанса через chiaki-ng. Скриншоты и сами кадры не передаются сервису перевода FRAIM; в текущей архитектуре отдельного облачного сервера FRAIM нет.
- **Распознанный текст:** OCR работает на устройстве (Google ML Kit). При выборе **Bergamot WebAssembly** перевод выполняется локально с моделью на устройстве без обращения к онлайн-сервису перевода.
- **Онлайн-режим MyMemory (необязательный):** при его выборе и согласии распознанный текст отправляется по HTTPS стороннему сервису. Провайдер может получать текст запроса, IP-адрес и служебные сетевые данные в соответствии со своей политикой. Не используй этот режим для конфиденциальных данных.
- **Подключение PS5:** регистрационные данные и ключи доступа, необходимые chiaki-ng для Remote Play, обрабатываются локально. Они **не должны** попадать в файлы профилей, запросы к переводчику или отчёты об ошибках.
- **Настройки:** области OCR, имена профилей, пресеты, тема и другая конфигурация хранятся локально. FRAIM не требует создания собственного облачного аккаунта.
- **Обновления:** приложение проверяет публичные релизы GitHub и при скачивании APK взаимодействует с GitHub/CDN. Эти сервисы видят стандартные сетевые метаданные запроса.

## Обмен профилями (FRAIM Beta v42)
Экспорт по выбору пользователя сохранит **только** название игры, координаты областей OCR, настройки отображения и вложенные пресеты в локальном JSON-файле. Импорт создаст новый профиль после проверки формата и подтверждения. В экспорт **не входят** данные PSN, IP-адрес консоли, ключи Remote Play, скриншоты, переведённые тексты и диагностические журналы. При выборе «Поделиться» файл передаётся приложению, выбранному самим пользователем; дальнейшую обработку определяет это приложение.

## Статус геймпада (Beta v43)
FRAIM считывает через системный API Android информацию о локально подключённом игровом устройстве: имя, состояние подключения и, если доступно, процент батареи и статус зарядки. Эта информация отображается локально и не включается в экспорт профилей или запросы к сервису перевода. Новые разрешения Bluetooth для функции не требуются.

## Translation Memory (Beta v44)
Пользовательский CSV с парами английских и русских строк импортируется в локальную базу SQLite внутри приватного хранилища приложения. FRAIM сопоставляет распознанный OCR-текст с локальными переводами **без отправки импортированного словаря в сеть**. CSV не входит в экспорт профиля игры. Если совпадения нет и пользователь включил MyMemory, обычный онлайн-перевод по-прежнему может отправлять распознанный текст внешнему сервису согласно согласию пользователя.

Установленная база удаляется при очистке данных приложения или удалении FRAIM. Встроенного облачного резервного копирования Translation Memory нет. Не импортируй файлы с данными, распространять или использовать которые ты не вправе.

## Как управлять данными
Выключение онлайн-перевода прекращает новые обращения к MyMemory. Уже переданный запрос нельзя отозвать. Очистка данных Android удалит локальные настройки и может удалить регистрацию консоли. Самостоятельно передавай файлы профилей только тем людям и через те сервисы, которым доверяешь.

FRAIM не имеет встроенной рекламы или обязательной оплаты. Наличие и поведение телеметрии сторонних Android-библиотек требуют отдельной проверки по их условиям. Не размещай в публичных Issue логи с токенами, домашние IP, пароли и личную переписку.
