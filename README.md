# FRAIM 💚

**FRAIM** — экспериментальное приложение для Android TV, которое помогает понимать игры на иностранном языке. Оно получает изображение из собственной сессии Remote Play, распознаёт текст на экране и переводит его.

**Состояние проекта:** ранняя Alpha, тестирование. **Официальный публичный APK ещё не выпущен.** Первый выпуск появится в [Releases](https://github.com/Lilpupok/FRAIM-releases/releases) после завершения проверок безопасности, подписи и лицензий.

## Что умеет FRAIM

- 🎮 Подключается к собственной PlayStation через встроенный клиент Remote Play на основе Chiaki-ng.
- 👁️ Распознаёт текст в игре с помощью OCR (Vision).
- 🟩 Позволяет передвигать и изменять область субтитров с пульта Android TV.
- ➕ Поддерживает вторую область распознавания по запросу, например для заданий или описаний предметов.
- 🌐 Экспериментальный Translate 0.1 переводит английский текст на русский с явного согласия пользователя.
- 🔄 Содержит основу для проверки обновлений в GitHub Releases.

FRAIM задуман **бесплатным приложением**. В будущем могут появиться добровольные пожертвования, но перевод не планируется прятать за платным доступом.

## Системные требования (раннее тестирование)

- Android TV / Google TV, включая Xiaomi TV Box S (3rd Gen).
- Собственная PlayStation и настроенное Remote Play.
- Сеть для Remote Play, а для тестового онлайн-перевода также доступ к интернету.

Совместимость с другими приставками и версиями Android TV ещё проверяется.

## Установка и обновления

Когда появится первый проверенный публичный выпуск:

1. Открой [Releases](https://github.com/Lilpupok/FRAIM-releases/releases).
2. Скачай подписанный `fraim-alpha.apk` из выбранного выпуска.
3. Установи APK на Android TV, подтвердив установку в системном диалоге.
4. Следующие версии можно будет проверять через раздел **FRAIM Updater** в приложении.

**Важно:** автоматическое обновление без удаления старой версии заработает только после перехода на постоянную цифровую подпись. Старые тестовые APK могли иметь несовместимые подписи.

Подробности: [установка и первые шаги](docs/INSTALL.md).

## Конфиденциальность

Vision распознаёт текст на устройстве. В экспериментальном **онлайн-переводе** текст реплик отправляется стороннему сервису **только после согласия**, но скриншот игры и пароль PSN не должны отправляться переводчику. Не вводи пароли PSN ни в какие сторонние формы, выдаваемые за FRAIM. Перед публичным релизом будет подготовлена подробная политика конфиденциальности.

## Лицензии и независимый статус

FRAIM не является официальным приложением Sony Interactive Entertainment и не связан с владельцами игровых брендов. PlayStation и названия игр принадлежат соответствующим правообладателям.

Сейчас приложение использует компоненты **Chiaki-ng** с лицензией **AGPLv3**. При публикации бинарного релиза будут предоставлены соответствующие исходники, уведомления об авторских правах и сведения о модификациях, требуемые лицензиями. До выполнения этих условий APK для массового скачивания не публикуется.
