# FRAIM Beta 💚
**Независимый переводчик игр для Android TV и Google TV**

**Разработчик:** **SHUK** · **Статус:** публичная Beta · **Последний опубликованный релиз:** v45 (17 ноября 2026 г.)

FRAIM позволяет играть в игры на другом языке через собственное подключение Remote Play к PlayStation: распознаёт текст в видеопотоке и показывает русский перевод. Приложение бесплатное; платных функций и обязательной подписки нет.

## Что умеет Beta
- 🎮 Подключаться к PS5 через встроенный клиент Remote Play на основе chiaki-ng; доступность и совместимость зависят от настроек устройства, сети и консоли
- 👁️ Распознавать английский текст через локальный OCR (Google ML Kit)
- 🌍 Переводить на русский автономным движком Bergamot WebAssembly; при выборе пользователя доступен альтернативный онлайн-режим MyMemory
- 🟩 Использовать две регулируемые области распознавания, например для реплик и заданий
- 📱 Сканировать весь экран по команде и выводить перевод текстовых блоков поверх оригинальных надписей (телефон, инвентарь, меню)
- 🗂️ Сохранять отдельные профили игр и несколько пресетов внутри профиля
- 🌗 Предлагать две темы и две иконки Orbit Dark / Orbit Light
- 📦 **Игровые языковые пакеты (v45):** профиль игры автоматически подключает свою базу переводов после установки `.fraimpack`. [Как это работает](docs/GAME_BUNDLES.md)
- 🧠 **Translation Memory (v44):** импортировать собственный CSV английский → русский, находить готовые реплики локально до запуска Bergamot и продолжать обычный перевод, когда совпадения нет. [Инструкция](docs/TRANSLATION_MEMORY.md)
- 🎮 Показывать подключение геймпада и доступный Android уровень заряда DualSense в «Системе» и быстром меню трансляции. Если прошивка не предоставляет данные батареи, FRAIM честно покажет «Заряд неизвестен»
- 🔄 Проверять GitHub Releases при запуске и по кнопке **Система → Проверить обновления**; установка APK требует подтверждения Android

**Известные ограничения:** Beta ещё требует проверки длительных игровых сессий и разных моделей приставок. В полноэкранном режиме нужно повторять сканирование после прокрутки; перевод поверх игры иногда закрывает фон подложками. Никакой гарантии идеальной синхронизации субтитров нет.

## Установка
1. Открой [официальные релизы FRAIM](https://github.com/Lilpupok/FRAIM-releases/releases/latest).
2. Скачай прикреплённый APK и установи на Android TV / Google TV (разреши установку из выбранного источника).
3. Подключи собственную PS5 через настройки Remote Play и настрой области текста.
4. Следующие версии устанавливай **поверх** текущей, не удаляя приложение, чтобы сохранить регистрацию PS5 и настройки.

**Почему файл иногда называется `fraim-alpha.apk`?** Это прежнее имя файла, сохранённое для совместимости со старыми апдейтерами. Оно **не** обозначает текущий статус приложения. Начиная с v42 основной файл называется `fraim-beta.apk`; старое имя дублируется исключительно для обновления предыдущих версий. Идентификатор Android `org.fraim.alpha` также остаётся неизменным ради безопасных обновлений.

Подробнее: [установка](docs/INSTALL.md), [политика конфиденциальности](docs/PRIVACY.md), [обмен профилями](docs/PROFILES.md).

## Общие профили (Beta v42)
Начиная с **FRAIM Beta v42**, в разделе «Профили игр» доступны экспорт, отправка и импорт файлов `.fraim.json`. Это позволяет передавать области OCR и пресеты без данных PSN. Подробности: [обмен профилями](docs/PROFILES.md).

## Безопасность и лицензии
FRAIM не связан с Sony Interactive Entertainment и не является официальным клиентом Sony. Проект использует компоненты chiaki-ng с условиями AGPLv3 и исключением OpenSSL; для каждого публичного APK рядом публикуется архив соответствующих исходников и контрольные суммы SHA-256. Проверка всех требований лицензий и сторонних библиотек продолжается. Подключай только собственную консоль и не публикуй пароли, регистрационные ключи или PSN-токены.

Прочитай [политику конфиденциальности](docs/PRIVACY.md).

[Библиотека общих профилей](profiles/README.md): пользователи могут публиковать настройки игр для общего доступа.
